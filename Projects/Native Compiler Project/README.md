# Native Compiler Project

Extend the Pascal-like interpreter into a native compiler that can produce an executable for an ARM64/AArch64 target.

## Milestones

1. Compile a tiny integer-only subset to ARM64 assembly.
2. Assemble and link that output into an executable.
3. Add variables, comparisons, and control flow.
4. Add stack frames for procedures, functions, and recursion.
5. Add runtime support for `WRITE`, `WRITELN`, strings, and reals.
6. Compare native output against the existing interpreter and VM.
