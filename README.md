# Notes

This repository is an Obsidian vault containing university notes, revision guides, worked examples, and a few planning/project pages.

## Main Areas

- [CS](CS/README.md) - broader computer science notes, organised by year and semester.
- [Projects](Projects/README.md) - project notes and project ideas kept separate from course notes.
- [Opportunities](Opportunities/README.md) - Internships, Spring/Insight Weeks, Graduate Schemes, Hackathons, etc.
- [ISE](CS/Y1S2/ISE/README.md) - `COMP1003` software engineering notes, revision guides, required reading notes, and exam prep.
- [Linear Algebra](<CS/Y1S2/Linear Algebra/README.md>) - chapter notes, concept pages, worked examples, and extra mock-exam practice.
- [Databases](CS/Y1S2/Databases/README.md) - database notes and exam-focused revision material.
- [PGP Java](<CS/Y1S2/PGP/Java/Java and OO Exam Guide.md>) - Java and object-oriented programming notes.
- [PGP Haskell](<CS/Y1S2/PGP/Haskell/Functional Programming Exam Guide.md>) - functional programming and Haskell notes.
- [AI Methods](<CS/Y2S2/AI Methods (10 Credits)/README.md>) - heuristic search, metaheuristics, evolutionary algorithms, and hyper-heuristics.
- [Image Processing](<CS/Y2S2/Image Processing/README.md>) - digital images, filtering, morphology, edges, segmentation, and coursework notes.
- [Distributed Systems](<CS/Y2S2/Distributed Systems/README.md>) - distributed systems lecture notes and slide index.
- [My Notes](../mynotes/README.md) - personal reading, music, and essay notes moved into the sibling `mynotes` vault.
- [Notion](Notion) - exported planning, reading-list, and task-tracker pages.

## Structure

- Most study areas have a `README.md` or exam-guide note that acts as the best starting point.
- Attachments usually live in local `_assets` folders beside the notes that use them.
- Obsidian configuration that is useful across machines is tracked in `.obsidian/`.

## Notes About Large Files

Some very large lecture-slide PDFs are intentionally excluded from Git so the repository can be pushed to GitHub without hitting file-size limits. They can still exist locally in the vault even if they are not tracked here.
