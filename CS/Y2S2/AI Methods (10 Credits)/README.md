## Topics Covered

- Heuristic search terminology, search spaces, neighbourhoods, and objective functions
- Construction heuristics and improvement heuristics
- Local search, hill climbing, and escaping local optima
- Metaheuristics and the trade-off between intensification and diversification
- Move acceptance rules and parameter configuration
- Hyper-heuristics and methods that search over heuristics rather than direct solutions

## Revision Focus

1. Know the difference between exact search, heuristic search, metaheuristics, and hyper-heuristics.
2. Be able to describe the components of a heuristic search method: solution representation, neighbourhood, move operator, evaluation function, and stopping condition.
3. Compare search strategies by how they balance exploitation and exploration.
4. Practise explaining why parameter settings affect performance and generalisation.
5. Use the hyper-heuristics slides to separate low-level heuristics from the high-level selection or generation method.
