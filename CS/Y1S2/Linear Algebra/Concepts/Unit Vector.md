# Unit Vector

## Definition

A [[Unit Vector|unit vector]] is a vector with length $1$.

That is, $\mathbf{u}$ is a unit vector if

$$
\|\mathbf{u}\|=1.
$$

## Why It Matters

Unit vectors are useful because they record direction without carrying extra length.

To normalise a nonzero vector $\mathbf{v}$, divide it by its length:

$$
\mathbf{u}=\frac{\mathbf{v}}{\|\mathbf{v}\|}.
$$

The result is a unit vector in the same direction as $\mathbf{v}$.
