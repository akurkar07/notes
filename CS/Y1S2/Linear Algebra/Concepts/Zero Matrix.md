# Zero Matrix

## Definition

The [[Zero Matrix|zero matrix]] is a matrix whose entries are all $0$.

For example,

$$
\begin{pmatrix}
0 & 0\\
0 & 0\\
0 & 0
\end{pmatrix}
$$

is a $3\times 2$ zero matrix.

## Why It Matters

The zero matrix represents the transformation that sends every input vector to the zero vector.

It also appears in homogeneous systems such as

$$
A\mathbf{x}=\mathbf{0}.
$$
