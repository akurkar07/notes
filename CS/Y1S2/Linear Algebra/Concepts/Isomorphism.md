# Isomorphism

## Definition

An [[Isomorphism|isomorphism]] is a linear transformation that is both one-to-one and onto.

Equivalently, it is an invertible linear transformation.

## Why It Matters

Isomorphic vector spaces have the same linear structure. For finite-dimensional spaces, this means they have the same dimension.

For a square matrix transformation $T(\mathbf{x})=A\mathbf{x}$, $T$ is an isomorphism exactly when $A$ is invertible.
